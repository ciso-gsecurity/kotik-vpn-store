Public download and presentation repository for Kotik VPN APK releases.

This repository intentionally contains no Android source code. Development is kept in the private product repository; this store repo publishes only:

- GitHub Pages download page;
- public `versions.json`;
- release notes;
- APK binaries as GitHub Release assets;
- SHA-256 checksums.
