Публичная страница загрузки APK-релизов Kotik VPN.

В этом репозитории намеренно нет Android-исходников. Разработка скрыта в приватном продуктовом репозитории; здесь публикуются только:

- страница загрузки GitHub Pages;
- публичный `versions.json`;
- заметки релиза;
- APK-файлы как GitHub Release assets;
- SHA-256 checksums.
