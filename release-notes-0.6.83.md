# Kotik VPN 0.6.83

Большой production patch для BLUE/KotikDNS.

## Что нового

- BLUE теперь подключается через bundled MasterDnsVPN client и KotikDNS.
- Public resolver для BLUE: `195.63.134.100:2053`.
- В APK добавлены native client binaries для `arm64-v8a`, `armeabi-v7a` и `x86_64`.
- WHITE и BLUE используют темную тему при выборе ноды.
- WHITE и BLUE показывают анимированных котиков на стадии подключения.
- Обновлены публичные зеркала `kotik.lets-mobile.ru` и `vpn.lets-mobile.ru`.
